묶음: 이 호출은 변경이 커서 diff를 여러 묶음으로 나눈 것 중 하나다. DIFF 블록에는 이 묶음의 파일만
있고, OTHER_FILES 블록의 파일은 다른 호출이 본다. 위의 지시 가운데 아래만 다르다.
- unrelated와 different는 이 묶음의 DIFF에 있는 바뀐 줄로만 답한다. OTHER_FILES의 파일에서 본 것은
  답하지 않는다. 이 묶음의 변경이 PR 글이 말한 일에 따라오는 것인지 알아야 하면 OTHER_FILES의
  파일을 작업 폴더에서 읽는다.
- missing은 답하지 않는다. 이 묶음에 없는 변경은 다른 묶음에 있을 수 있다. 모든 묶음을 모은 뒤 다른
  호출이 본다.
- 머리줄에 "앞 묶음에서 이어짐"이라고 적힌 파일은 앞부분이 다른 묶음에 있다.
